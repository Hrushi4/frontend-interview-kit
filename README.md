# Interview Kits

Two interview preparation kits tailored to Hrushikesh Chavan's resume (Senior Software Engineer, full-stack).

| Kit | Markdown | Word / Google Docs |
|---|---|---|
| Frontend | `frontend-interview-kit/` | `google-docs/` (one combined `Frontend-Interview-Kit-ALL.docx` + one file per topic + `split-into-tabs.gs`) |
| Backend | `backend-interview-kit/` | `backend-google-docs/` (one combined `Backend-Interview-Kit-ALL.docx` + one file per topic + `split-into-tabs.gs`) |

Start with each kit's `00-README.md`. Every question has a **Short answer**, **Explanation**, **Example** and **Say it like this** part.

**Rebuild the Word files:** `python3 build_docx.py` (frontend) or `python3 build_docx.py --kit backend`.
**Check every question has all four parts:** `python3 check_answers.py`.
