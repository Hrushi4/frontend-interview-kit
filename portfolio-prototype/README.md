# Portfolio prototype

`index.html` is an interactive prototype of a portfolio site built from the resume. It is a design reference, not the finished site. Open it in a browser to try it.

What it shows:

- **Hero with measurable metrics:** every number opens to show how it was measured.
- **"Break the call" demo:** simulates LiveKit reconnects (resume, rejoin, TURN over 443).
- **Case studies:** InterpretIQ, BpoBox, the AI pipeline and the security audit, each with context, role, a flow diagram, results and "what I'd change".
- **Pipeline lab:** a concurrency slider showing where the 5x throughput came from and where rate limits cap it.
- **Security matrix:** authorisation results for each role and endpoint, before and after the audit.
- **Accessibility demo:** call controls with a visible screen-reader log.
- **Interview mode:** presenter notes in every section, section navigation and a 2-minute timer.
- **Command palette:** Cmd/Ctrl+K.

The numbers inside [square brackets] are placeholders. Fill them in with your real measurements before you publish.
