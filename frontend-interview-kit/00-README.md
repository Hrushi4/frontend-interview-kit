Original question bank built around **your** profile: Senior Software Engineer, 4+ yrs, React 19 / TypeScript / Redux / Next.js, plus NestJS / FastAPI exposure, LiveKit real-time video, RBAC/JWT security, SSE, and LangChain AI scoring.

## How to use this kit
Every topic file goes from basic to advanced:
- **🟢 Basic** — fundamentals asked in screening rounds; never miss these.
- **🟡 Intermediate** — the bulk of senior frontend rounds.
- **🔴 Advanced** — product companies, senior/staff loops, deep follow-ups.
- **🧩 Scenario** — "what would you do if…" questions that test judgment.
- **🎯 From Your Resume** — questions an interviewer will ask *because of what you wrote*. Practise these out loud.

How to study a file: read Basic quickly, answer Intermediate out loud before reading the answer, attempt Advanced code yourself first, then do Scenario questions as mock interview prompts.
